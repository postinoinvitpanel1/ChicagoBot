# ربات شیکاگو (Chicago)

این پروژه یک ربات ساده تلگرام است که دستورهای `/start`، `/help` و `/id` را دارد.

## راه‌اندازی کلی
1. در تلگرام به `@BotFather` برو و با دستور `/newbot` یک ربات بساز.
2. توکن ربات را کپی کن؛ توکن را در چت عمومی یا داخل فایل‌های پروژه قرار نده.
3. این پوشه را در یک سرویس میزبانی که از Python worker پشتیبانی می‌کند یا در GitHub بارگذاری کن.
4. در بخش Environment Variables / Secrets یک متغیر با نام `BOT_TOKEN` بساز و توکن را به عنوان مقدار وارد کن.
5. دستور اجرا: `python main.py`

## نکته
این ZIP به‌تنهایی ربات را آنلاین نمی‌کند؛ باید توکن واقعی و یک سرویس میزبانی فعال داشته باشی.
برای اضافه کردن امکانات، اول مشخص کن ربات شیکاگو دقیقاً چه کاری انجام بدهد.
